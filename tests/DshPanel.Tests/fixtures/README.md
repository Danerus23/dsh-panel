# Записанные страницы цен — фикстуры разбора (DEF-056)

**Что здесь.** Три ЖИВЫЕ страницы сайта цен DeepSeek, снятые 24.10.2026 одним прогоном,
без правок и без вырезок — такими, какими их отдал сайт. На них проверяется разбор
(`PricingPage.Parse`) и решение об адресе (`PricingDecisions.Url`).

| Файл | Адрес | HTTP | Байт | Что это |
|---|---|---|---|---|
| `pricing-en-shell.html` | `https://api-docs.deepseek.com/quick_start/pricing` (**без слеша**) | 200 | 49 316 | **КОРНЕВАЯ страница сайта** (`<title>Your First API Call`): таблицы цен нет. Именно её панель получала с 22.10.2026 и говорила «цены прочитать не удалось» |
| `pricing-en.html` | `https://api-docs.deepseek.com/quick_start/pricing/` (**со слешем**) | 200 | 26 043 | Настоящая страница цен: `<title>Models &amp; Pricing`, две модели, цены в USD |
| `pricing-zh.html` | `https://api-docs.deepseek.com/zh-cn/quick_start/pricing/` | 200 | 26 182 | То же по-китайски: `<title>模型 &amp; 价格`, цены в юанях |

**Почему без слеша — оболочка.** Так ответил сам сайт: код 200 и корневой документ. Редиректа
нет, поэтому «слеш на конце» — часть адреса, а не оформление (`docs\PRICING.md` §2 предупреждал,
что код ответа здесь ничего не доказывает).

**Чем проверяется.**

* `PricingTests` — разбор всех трёх страниц: оболочка называется словами (`PricePageShell`),
  настоящая страница даёт шесть чисел flash и шесть v4-pro, китайская — юани;
* модель берётся ПО ИМЕНИ из профиля агента (`AgentProfile.PricingModel`), а не «первая колонка»:
  `deepseek-chat` на странице нет → ответ «нет модели, чужие цены не подставляются»;
* `PricingPage.LooksLikePricingPage` — «документ тот самый» по заголовку (EN и ZH).

⚠️ **Это снимок на дату, а не текущее состояние сайта.** Страницу перепишут — фикстура останется
правдой о том, что было, и прогон покажет, что разбор на новой странице не сработал.
