# Телефонный пульт — веб-слой (S1 + S2)

React 19.3.1 + Semi 2.104.0 + Vite 8.3.5, TypeScript 6.0.3. **S1 «Видеть»:** вход по шести цифрам,
список сессий, открытая сессия с живым потоком. **S2 «Отвечать»:** карточка вопроса внутри
сессии — варианты, «свои слова», ответ одним набором, двухшаговая отмена; отдельного экрана
вопроса нет, и ссылки на старую страницу `/ask` в пульте тоже нет (сама страница остаётся
прямым запасным адресом до отдельной уборки).

**Границы.** Здесь только клиент. Калитка (C#) — `src/DshPanel/Server/PhoneGate.cs`; движок и
данные владельца этот слой не трогает. Своего словаря слов у веба нет: слова приезжают в
`boot.words`, паритет трёх языков сторожит `src/test/i18n.test.ts`.

## Команды

```powershell
npm ci                 # точные версии из package-lock.json
npm run typecheck      # tsc --noEmit
npm run lint           # eslint src
npm run format:check   # prettier --check …
npm run test           # vitest run (unit)
npm run build          # → ..\DshPanel\WebAssets (эта папка коммитится)
npm run e2e            # playwright, канал msedge, 360×800, свой стенд
npm run check:assets   # пересобрать во временную папку и сверить SHA-256 с деревом
npm run check:words    # страница ТОЛЬКО на словарях панели: имён ключей на экране — 0
```

`npm run e2e` поднимает **подставную калитку** `e2e/server.mjs` (порт 43217): живой движок и
данные владельца для проверки экрана не нужны. Двери стенда повторяют контракт §2.

## Что отдаётся калитке

Сборка кладёт в `WebAssets`:

| Файл | Что это |
| --- | --- |
| `assets/main-<hash>.js`, `assets/main-<hash>.css` | код и стили (только свои, ни одного внешнего адреса) |
| `shell.html` | оболочка с подстановками — её заполняет калитка |
| `assets.json` | карта: `js`, `css` (полные пути `/assets/…`), `shell`, список подстановок |
| `manifest.json` | манифест Vite |

Подстановки `shell.html` (калитка заменяет и **HTML-экранирует**):

| Метка | Что подставить |
| --- | --- |
| `__LANG__` | `ru` / `en` / `zh` |
| `__TITLE__` | `PhonePageTitle` |
| `__BOOT__` | JSON `{lang, authed, device, words}` — в атрибут `data-boot`, экранировать `& < > " '` |
| `__LOADING__` | `PhoneWebLoading` (подпись, пока скрипт не загрузился) |
| `__BOOT_FALLBACK__` | `PhoneWebBootFallback` (что делать, если подпись не исчезла) |
| `__NOSCRIPT_TITLE__` / `__NOSCRIPT_TEXT__` | `PhoneWebNoScriptTitle` / `PhoneWebNoScript` |
| `__JS__` / `__CSS__` | пути из `assets.json` |

Маршруты: `/` — список, `/?session=<id>` — сессия. Истории на сервере нет; неизвестный путь
калитка отдаёт `404` словами сама.

## Проверки, которые обязаны падать

Unit (`vitest`): разбор `boot`, строки списка и состояния, нормализация записей и дедупликация
черновика, отступ/сторож потока, такт опроса, контраст токенов формулой, паритет трёх словарей.
E2E (`playwright`): вход (отказ сохраняет введённое), список (слова состояний, лимит, пусто,
ошибка, 320 px без прокрутки, тёмная тема), сессия (лента, черновик → готовый ответ, «раньше»,
фокус на строку), отказы (без JS, скрипт не загрузился, сломанный рендер, 429-эквивалент).

Мутации, которыми проверено, что они падают — в отчёте роли
`_team/250/s1s2-screens.md` (раздел «чем проверяется»).
